# Sprint Web Dev

Landing page desenvolvida em React, apresentando o produto através de seções como Hero, Problema, Como Funciona, Percepção, Demo, Jornada, Autonomia, MVP, Diferenciais e Evolução.

## Tecnologias utilizadas

- **React 19** — biblioteca para construção da interface
- **Vite** — bundler e servidor de desenvolvimento
- **JavaScript (JSX)**
- **CSS puro** — estilização dos componentes (um arquivo `.css` por componente)
- **ESLint** — padronização e verificação de qualidade do código

## Como instalar as dependências

Pré-requisito: ter o [Node.js](https://nodejs.org/) instalado (recomendado versão 18 ou superior) e o `npm`.

Na raiz do projeto, execute:

```bash
npm install
```

## Como executar o projeto

Para rodar em modo de desenvolvimento:

```bash
npm run dev
```

O terminal exibirá o endereço local (geralmente `http://localhost:5173`) para acessar a aplicação no navegador.

Outros comandos disponíveis:

```bash
npm run build     # gera a versão de produção na pasta dist
npm run preview   # serve localmente a versão de produção já buildada
npm run lint      # executa a verificação de lint no código
```

## Usuários e senhas para teste

Este projeto **não possui autenticação/login**. Todas as páginas e seções são de acesso público, portanto não há usuários ou senhas necessários para teste.

## Uso de Inteligência Artificial no projeto

A Inteligência Artificial foi utilizada como ferramenta de apoio ao longo do desenvolvimento, principalmente em três frentes: no **refinamento da estilização dos arquivos CSS**, ajudando a ajustar detalhes visuais, espaçamentos e responsividade dos componentes; na **orientação para a criação da estrutura dos componentes** React, auxiliando na organização das pastas e na divisão do projeto em componentes reutilizáveis; e na **revisão geral do código**, identificando pontos de melhoria, inconsistências e boas práticas a serem aplicadas. Todas as decisões finais de implementação e o entendimento do código produzido foram validados pela equipe de desenvolvimento.
